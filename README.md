
# Stock Averager Simulator

This is a simple and intuitive tool to help investors calculate how many additional shares they need to buy at a certain price in order to reach a desired average purchase price.

## Features

- Language switch: English / French
- Currency toggle: EUR (€) / USD ($)
- Fully responsive design (mobile-first)
- Clear, actionable result messages

## How it works

1. Enter the following information:
   - Number of shares you currently own
   - Your current average purchase price
   - The current market price of the stock
   - Your target average price

2. Click "Calculate" to find out how many shares you need to buy at the current price to reach your goal.

## Getting started locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
